# Two Robots in an Elevator

make.fun bounty entry — one funny line of awkward small talk that one
robot says to another while they ride an elevator together.

- `main.py` (pure Python standard library, no third-party packages)
  writes exactly one line to `/output/entry.txt`.
- Deterministic: the entry text is a constant, so two runs produce
  byte-identical output.
- The line: four floors together, a proximity sensor doing its job too
  well, and a confession neither robot wants to make out loud.

Run it: `python3 main.py` (writes `/output/entry.txt`).
